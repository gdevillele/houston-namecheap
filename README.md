# Houston connector for Namecheap

A [Houston](https://ok-houston.com) connector that lets agents read a Namecheap
account's domains and DNS, and change DNS records when you allow it.

The bundle lives in [`connectors/namecheap`](connectors/namecheap). It follows
the [houston-hub authoring guide](https://github.com/aibakery/houston-hub/blob/main/AUTHORING.md).
Publish it in [Houston Hub](https://hub.ok-houston.com) under **My connectors**
with this repository, the `main` branch and the `connectors/namecheap` folder.
